개인정보처리방침

시행일: 2026년 11월 27일

1. 대상

이 방침은 유튜브 채널 "구국열사" 운영자가 자기 채널에 쇼츠를 올리기 위해 쓰는 개인용 자동화 도구 "CEO Shorts"(이하 도구)에 적용됩니다. 도구는 운영자 1인만 사용하며, 외부 이용자를 받지 않습니다.

2. 이용하는 구글 사용자 데이터

  • 권한: YouTube 동영상 업로드(https://www.googleapis.com/auth/youtube.upload) 한 가지입니다.
  • 용도: 도구가 만든 영상을 운영자 본인의 유튜브 채널에 업로드하는 데만 씁니다.
  • 도구는 시청 기록, 구독, 댓글, 이메일, 연락처 등 다른 구글 데이터를 읽거나 저장하지 않습니다.

3. 보관과 보호

  • 업로드 권한 토큰은 GitHub Actions 비밀값(Secrets)에 암호화되어 보관되며, 코드나 공개 파일에 기록하지 않습니다.
  • 영상 제작에 쓰인 임시 파일은 작업이 끝나면 삭제됩니다.

4. 제3자 제공

구글 사용자 데이터를 제3자에게 판매하거나 제공하지 않습니다. 영상 제작에는 Pexels(스톡 영상)와 음성 합성 서비스가 쓰이지만, 이들에게 구글 사용자 데이터는 전달되지 않습니다.

5. 권한 철회

운영자는 언제든지 구글 계정의 서드파티 앱 접근 설정에서 도구의 권한을 철회할 수 있습니다.

6. 문의

문의는 유튜브 채널 구국열사로 해 주세요.
